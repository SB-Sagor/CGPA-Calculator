# CGPA & GPA Calculator (NITER-constituent institute of the University of Dhaka)

A mobile application built with **Flutter** to calculate **GPA** and **CGPA** based on the official credit system of  
**National Institute of Textile Engineering and Research (NITER), Constituent Institute of University of Dhaka**.  

---

##  Purpose
This app is designed for **NITER students** to easily calculate their semester GPA and overall CGPA.  
It follows the **University of Dhaka credit rules** and provides a simple, user‑friendly interface.

---

##  Features
- **[GPA Calculation](ca://s?q=GPA_calculation_in_Flutter_app)** → Select grades for each course and get instant GPA.  
- **[CGPA Calculation](ca://s?q=CGPA_calculation_in_Flutter_app)** → Combine all semesters to calculate cumulative CGPA.  
- **[Semester‑wise Input](ca://s?q=Semester_wise_GPA_input_in_Flutter_app)** → Manage GPA for up to 8 semesters.  
- **[Credit System](ca://s?q=NITER_credit_system_for_CGPA_calculation)** → Uses NITER’s official course credits.  
- **[Offline Support](ca://s?q=Offline_support_in_Flutter_CGPA_app)** → Works without internet.  
- **[APK Installation](ca://s?q=Install_APK_for_Flutter_CGPA_app)** → Direct APK available for Android devices.  

---

##  Tech Stack
- **Flutter** → Cross‑platform mobile framework  
- **Dart** → Programming language  
- **MVVM Architecture** → Clean separation of UI and logic  
- **Firebase (optional)** → For backup and sync (future scope)  

---

##  Getting Started
1. Download the APK from releases.  
2. Install on your Android device.  
3. Open the app → Choose **GPA** or **CGPA** calculation.  
4. Select semester → Enter grades → Get instant result.  

---

##  Example
- **Semester 6 GPA**:  
  - CSE‑3201 – Operating Systems (Credit: 3.0)  
  - CSE‑3202 – Numerical Methods (Credit: 3.0)  
  → GPA calculated based on selected grades.
